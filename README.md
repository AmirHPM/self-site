# Amirhossein Pirmohammadi — Personal Portfolio

A bilingual (Persian/English), responsive, creative personal portfolio built with plain HTML, CSS and JavaScript.

## Preview locally
Open `index.html` in a browser. The language switch is in the top navigation. The selected language is saved in the browser.

## Publish with GitHub Pages
1. Create a new public repository on GitHub. For a user site, name it `YOUR-USERNAME.github.io`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. GitHub Pages will publish the site at `https://YOUR-USERNAME.github.io`.

## Before publishing
- Replace the LinkedIn placeholder in the contact section with the correct profile URL.
- Verify the email address.
- Review all dates and translated job titles carefully.
- Add only real projects/case studies and measurable results that you can substantiate. This version intentionally does not invent campaign results, budgets, team sizes or performance metrics.
- The English date labels are approximate Gregorian conversions of the Persian CV dates. Confirm exact month conversions if precision is important.

## Files
- `index.html` — bilingual site content
- `style.css` — visual design and responsive layout
- `script.js` — language switch, mobile navigation and footer year
